{# Add-to-home-screen for a bookmark page (desktop and mobile both -- beforeinstallprompt is the same API on desktop Chrome/Edge as it is on Android; there is no separate "desktop" install trick). This partial is page-agnostic -- the page itself has to put its own in its head_extra block (see main.py's INSTALLABLE_PAGES for the valid PAGE keys); this reads that same link to get the app's own name for the banner text, rather than needing it passed in twice. Chrome/Edge only offer to install a page that has BOTH a manifest and a registered service worker -- this registers /sw.js (a no-op; see main.py for why) the first time any bookmark page loads, then listens for the browser's own beforeinstallprompt event. A BANNER, NOT JUST A BUTTON. A small ghost button sitting at the bottom of the page is easy to never notice -- Jason's own ask was for something that actively asks, like a notification. So once the browser says the page is installable, a dismissible bar drops down from the top saying so, with Install / Not now. "Not now" is remembered (localStorage) so it does not nag on every visit -- the small button lower on the page (unchanged) is still there afterward if they change their mind. iOS Safari never fires beforeinstallprompt at all -- Apple has never shipped it -- so this shows two-tap instructions there instead of a banner that would never do anything. #}
