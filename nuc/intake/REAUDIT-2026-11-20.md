## Fix list (proposed T0931, about 4h)
### Must (data safety)
1. Verify a piece BEFORE writing it: buffer it (16 MB max), check length and sha256, then one pwrite. If n is already
   in .got, answer 200 with no write. If .finishing exists, answer 409. (resumable.py:202-214)
2. Finish vs. late pieces: per-upload flock (writers shared, finish exclusive). (resumable.py:200, 270-281)
3. Reserve disk space at start with posix_fallocate, so ENOSPC gives 507 up front, and catch ENOSPC on pieces.
   Cap the number of open uploads per email. (resumable.py:127-136)
4. On startup, remove stale STAGE/*.finishing. Today a restart mid-finish leaves a 1 h lock. (resumable.py:61, 264)
5. Write the result and meta atomically: tmp file, then os.replace. (resumable.py:140, 304)
6. /share and /intake: move a failed file to .failed instead of deleting it. (share.py:302-304, app.py:264-265)
### Should (security)
7. Refuse to start when INTAKE_KEY is unset. (app.py:130)
8. Allow writes only when the level is `full`, plus an explicit exception for the keyed PC service. (app.py:135)
9. Run safe_name at /up/start and in /share (NUL, control characters, newlines). (resumable.py:118, share.py:258)
10. /intake gets its own token, separate from the drop key. (app.py:231-247)
11. Require the piece checksum on the parallel path, or send a whole-file sha256 at start. (resumable.py:197)
12. Stale-lock takeover by rename or flock, not touch. (resumable.py:264-266)
### Should (ops)
13. Hourly sweep of .part, .work and .tmp by age; show the .failed count and NAS mount sentinels in healthz.
14. Log start, finish and kept with uid, size and status; rotate intake.log.
15. Idempotent /up/start: the client key is a hash of name, size and lastModified.
16. Semaphore(1) around ask_model.
17. Errors are plain words: no raw `{e}` text sent to the client.
### UI
18. sendLink: check res.ok and that the answer is an array (otherwise one 403 locks the sending page for good).
    (atomic_ui.py:356)
19. Link-only share: remove `indet` and set 100% when done. (atomic_ui.py:317, 385)
20. Stop the pulse in the error state; no requestAnimationFrame while reduced motion is on. (atomic_ui.py:238, 303)
21. 5xx says "The server is busy. Trying again…", not "Signal lost". (atomic_ui.py:105, 218)
22. aria-valuetext on #bar; fewer aria-live regions; beforeunload while sending; track contrast 3:1; #nums >= 16px.
### Tests
23. Teach test_finish, test_gatekeeper and test_resumable to send X-Drop-Key and take paths as arguments. Add tests
    for: a damaged re-send of a piece that already arrived, a restart mid-finish, and ENOSPC.
