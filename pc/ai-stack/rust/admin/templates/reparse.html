Re-parse from source

Re-reads each recipe's original link with Phi-4 instead of however it was first imported, then makes the steps more detailed and converts measurements to imperial -- fixes thin, single-paragraph recipes into real, followable steps. Never invents a quantity, time or temperature the recipe didn't already state. A recipe with no source link (typed or pasted in by hand) has nothing to re-fetch, so it gets "Add detail" instead -- same detail/imperial pass, run on what's already there. One at a time, on purpose: each button is a real fetch and/or a real model call, so it takes a few seconds to a minute. Step pictures aren't carried over automatically afterward (the old ones don't line up with new steps) -- use "Draw step pictures" to fill them back in; that button frees whatever Ollama has loaded first, on its own, so the drawing model always has room.
